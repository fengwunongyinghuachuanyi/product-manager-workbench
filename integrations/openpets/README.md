# OpenPets 工作台内嵌模块

使用入口：设置 → 桌面宠物；双击角色进入陪伴面板。

目录：source/ 为 OpenPets 原始源码，kit/ 为原生引擎及本机适配，independent-source/ 为大肥鱼独立版源码、行为引擎与运行素材，pets/deepseek/ 为原始 V2 素材与转换后的 33 个动作，native/ 为工作台宿主、构建与几何验收程序，runtime/WorkbenchPet.app 为当前 Apple Silicon / macOS 14+ 私有原生宿主，verification/ 为指纹、差异与验收记录。

重新构建：在应用根目录运行 `zsh integrations/openpets/native/build.sh`。动作图集重新生成：在 AionUi 目录运行 `node ../integrations/openpets/native/build-companion-atlases.cjs`（需已有 sharp 依赖）。几何验收：`zsh integrations/openpets/native/test-companion-physics.sh`。

本机 CLT 6.1.2 的 SwiftPM Manifest 动态库与接口不匹配，构建脚本直接编译 Kit 源码并生成资源访问器；重复模块通过私有 VFS overlay 处理，不修改系统文件。Swift 模块缓存固定在 runtime/build/module-cache。迁移架构或制作正式安装包需重新编译并把运行资源及许可证随包携带；本次安装用于当前源码运行的工作台，未制作签名 DMG。

V2 完整 192×208 单元格避免脚部裁切；120px 档位为 120×130 画布。原始 spritesheet.webp 保留。Kit 修改详见 verification/source-changes.patch；新增文件与工作台源文件指纹见 verification/companion-source-files.json。

# 大肥鱼桌宠：工作台接入与使用说明

更新日期：2026-10-19。已安装到当前这台 Mac 的产品经理工作台，保持 120px 迷你尺寸和完整脚部显示。

## 打开和入口

双击同目录的「打开产品经理工作台.command」。桌面程序启动后可以关闭终端。正常退出工作台会关闭桌宠；仅关闭工作台主窗口时，桌宠仍可使用。

设置 → 桌面宠物可以启用、关闭、调整大小和免打扰。

- 单击角色：摸摸。
- 双击角色：打开「陪伴」小窗；重复打开复用同一窗口。
- 右键角色：摸摸、喂一口、聊天与陪伴面板、开始 25 分钟专注、睡觉和叫醒。
- 拖动角色：调整位置，松手后在开启窗口互动时落向窗口边缘或桌面底部。
- 小窗上方「陪伴」返回功能面板，「新对话」进入助手选择。

## 已接入的功能

| 功能 | 使用方式与行为 |
| --- | --- |
| 摸摸 | 单击角色或面板「摸摸」，播放互动动作与回应。 |
| 喂食 | 点击「喂一口」，播放吃东西动作；饱腹值每次加 12，最高 100，并随时间变化。 |
| 聊天 | 点击「聊天」选择工作台现有助手。支持 Codex CLI、Agent 蓝图 2.0、拆拆等已有助手；隐藏助手在「更多」中选择。 |
| 专注计时 | 选择 1–120 分钟，默认 25 分钟；显示倒计时，完成后提醒并记录次数，可提前结束。计时在主进程运行，关闭小窗不会停止。 |
| 接口粮小游戏 | 点击「开始游戏」，在 30 秒内点击出现的米饭接粮；显示得分、剩余时间与最好成绩。这里是游戏内的虚拟口粮，与真实模型额度无关。 |
| 随机小动作 | 陪伴模式下，按独立版行为逻辑随机出现动作；安静陪伴、专注和 AI 工作状态会抑制相应的自动打扰。 |
| 睡觉 | 点击「睡一会儿」保持睡眠姿势，点击「叫醒」唤醒；摸摸或喂食也可以唤醒。长时间空闲也会触发独立版的休息逻辑。 |
| 窗口边缘与跟随 | 开启「站在窗口上」，点击「站到当前窗口」，优先站到工作台的可见窗口上沿；随后跟随该窗口移动。窗口消失、最小化或支撑边缘被遮挡时重新落下。也可以拖动角色到合适的位置。 |

窗口上方需要留出容纳角色的空间；找不到合适的工作台窗口时会选择其他可站立窗口。窗口互动读取窗口位置和尺寸，不采集画面。当前实现针对普通可见窗口，特殊全屏窗口、不同应用的特殊浮层和所有多屏组合未逐一做人工验收。

## 聊天、任务提醒和结果

聊天小窗复用工作台原有会话、流式回复、附件、权限确认和模型设置。使用现有 Codex CLI 的 ChatGPT 登录时，模型仍在云端推理；无需为桌宠单独配置模型接口。其他助手仍依赖它们已有的服务与工具配置。

AI 开始、处理、完成、失败会显示对应状态；完成气泡的「查看结果」保留 120 秒，打开该气泡对应的原会话。小窗的「在工作台查看」也会定位当前会话。主窗口已关闭时，会重新创建主窗口并定位结果。多个结果在窗口启动期间连续打开时，最终定位最近一次点击。

宠物状态连接只转发会话标识和状态，不复制提示词、正文、文件、工具参数或密钥。工具授权沿用聊天界面。免打扰会抑制自动状态提醒；手动互动和打开小窗仍可用。

## 保存的数据

数据保存在 `~/Library/Application Support/AionUi-Dev/openpets/`：

- positions.json：桌宠位置。
- companion.json：饱腹值、专注结束时间与完成次数、窗口互动偏好、睡眠状态、游戏最好成绩等。
- host.log：原生宿主日志。

游戏当前局不会跨重启继续；最好成绩保存。专注结束时间会跨重启恢复，程序完全退出时不在后台弹出提醒；下次启动时按结束时间结算。启用、尺寸和免打扰沿用工作台偏好存储。

## 原项目与本机适配

OpenPets 提供 macOS 原生引擎、任务气泡、动作跳转、自定义宠物、MCP/CLI/Swift 接入，以及内置电量和 Claude Code/Codex 额度插件。本工作台使用它的原生 Kit；没有自动启动配额插件、公共 MCP 服务或独立菜单栏程序。外部插件商店与外部插件安装在核对的上游版本中仍属规划功能。

大肥鱼独立版原有摸摸、喂食、聊天、专注、接口粮、随机动作、睡觉、窗口边缘互动，以及可选画面分享、鼠标穿透等。本次将用户指定的八项能力适配到工作台；未接入画面分享或全局鼠标穿透。

保留独立版原始 behavior.cjs 和 motion.js 行为与动作定义；聊天连接工作台现有助手，小游戏使用工作台小窗交互，窗口物理改为适配 macOS 的原生实现。角色动作图集按原动作帧与时长转换为 OpenPetsKit 可读格式，并保留原始素材与许可证。
