# Agent 蓝图 2.0 · 个人工作台集成

本目录包含蓝图项目本身，以及将原 Python 引擎连接到工作台的适配器。

## 放置位置

蓝图具有连续阶段、规则选型、审稿和缓存状态，适合以「助手」作为操作入口，以 MCP 工具承接 Python 执行，并把源材料与成果保留在本地文件中。

| 工作台板块 | 蓝图的用途与接入状态 |
| --- | --- |
| 助手 | 已创建并启用「Agent 蓝图 2.0」，配置使用规则、提示示例与专用 MCP。 |
| 工具 / MCP | 已导入 agent-blueprint-2，并在应用中通过连接测试，显示 7 个工具。 |
| 文件 / 项目 | 原蓝图项目已内置于 engine，且已加入蓝图验收会话的文件区；任务成果存入 runs。新会话也可通过 MCP 使用内置引擎。 |
| Agents | 复用本机可用的 Codex CLI，由它复用 ChatGPT 登录；模型推理发生在云端。 |
| 技能 | 保留原项目的 skills 参考文件，执行规则已配置在专用助手中。当前执行通过 MCP；源 skills 参考文件没有被自动安装到全局技能中心。 |

团队、定时任务和模型对比各自面向多人分工、周期执行及输出比较。本次蓝图推导以用户提交的具体任务为单位，放在助手入口即可开始使用；日后可按需要从团队或定时任务引用该助手。

- `engine/`：从用户指定的桌面项目复制的 146 个项目文件（含原目录附带的 PDF），含 Python 引擎、BLUEPRINT.md、17 个组件、技能参考、示例和许可证。原桌面文件不变；运行不依赖桌面目录。来源和 SHA-256 在 `skill/source-manifest.json`。未复制 Git 历史、缓存和密钥；保留原目录附带的 PDF 文件。
- `bridge.py`：实现原引擎 Runner 协议；使用本机已登录的 Codex CLI，通过 ChatGPT 账号调用 OpenAI 云端模型。没有离线模型，没有另存 API Key 或复制登录凭据。
- `server.mjs`：MCP 连接器；复用工作台已有的 MCP SDK。`mcp.json` 是可重新导入的本机配置。
- `runtime/`：Python 3.12 虚拟环境，使用本机 Codex 随附 Python，不需要安装原 Anthropic 依赖。
- `runs/<任务ID>/`：任务信息、累计用量、模型调用记录、阶段缓存与 Markdown/JSON 成果。
- `config.json`：模型、CLI 路径、思考强度和默认预算。当前模型沿用本机 gpt-6.1-sol，high。

当前电脑的系统代理已启用 `http://127.0.0.1:7900`。适配器与工作台的 Codex Agent 环境变量沿用该地址，NO_PROXY 保留本机直连；切换系统代理端口或停用代理后应同步调整。

## 在工作台中使用

助手列表选择「Agent 蓝图 2.0」，新建对话后输入点子/PRD，或明确指定待分析项目目录。助手使用 Codex CLI 引擎与 agent-blueprint-2 MCP 工具。

`engine/启动引擎.command` 和 `engine/setup.sh` 是原项目保留的 Anthropic 接口启动方式；本次 ChatGPT 集成使用工作台助手入口和 `bridge.py`，无需运行那两个原启动脚本。

## 执行和证据边界

正向保留原引擎：需求拆解 → 五要素建模 → 规则选型 → 架构设计 → 新上下文审稿；未通过时只按原规则重写和复审一次。逆向保留本地静态扫描、意图反推、组件对照和复核。审稿使用同一模型的独立调用，不代表不同模型或人工验收。

结果 completed 表示流程完成且模型审稿通过；completed_draft 表示流程已产出草稿但审稿未通过。项目扫描结果及其完成度是静态启发式，不能证明产品功能、质量或生产可用性。

默认最多 16 次模型调用、40 万累计输入/输出 token。调用在开始前计数，错误和重试也占次数；续跑不清零预算。token 采用 CLI 返回的实际 usage，在每次调用前检查，单次请求可能越过 token 阈值；中断且未返回 usage 的请求无法完整计量，不构成订阅额度或费用的硬上限。额度仍受 ChatGPT/Codex 账号限制。单个阶段最多等待 10 分钟。

续跑使用原引擎的输入、模型、提示和缓存内容哈希校验。只复用有效且一致的阶段；模型/输入变化或缓存损坏会重算。只允许一个任务同时运行。取消保留已有阶段。

模型阶段禁用 Shell、浏览器和 MCP 等工具，并使用只读沙箱。仅将本阶段的点子、PRD 或项目扫描摘要发送给云端模型。逆向分析不自动执行项目、不修改被分析目录；生成成果也不自动实施或发布。

本目录适配器是个人本机集成，配置中的绝对路径和 Python 虚拟环境需要在迁移电脑后重新配置。以后若制作安装包，需要将本目录纳入安装资源并重新定位运行时。
